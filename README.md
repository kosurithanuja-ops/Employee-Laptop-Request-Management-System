# Employee Laptop Request Management System

## 📌 Project Overview

The Employee Laptop Request Management System is a ServiceNow-based application designed to automate and simplify the process of requesting and managing laptops for employees.

The system allows employees to submit laptop requests through a catalog item. The request is processed through an automated workflow that includes manager approval and task assignment to the laptop fulfillment team.

## 🎯 Objectives

- Automate the employee laptop request process
- Reduce manual work and processing time
- Provide a structured approval process
- Automatically create fulfillment tasks
- Improve request tracking and management

## 🛠️ Technologies Used

- ServiceNow
- Service Catalog
- Flow Designer
- Business Rules
- User Administration
- Groups and Roles
- ServiceNow Tables

## ⚙️ Key Features

- Employee laptop request submission
- Laptop configuration through catalog variables
- Manager approval workflow
- Automatic catalog task creation
- Assignment to Laptop Fulfillment Team
- Request tracking
- Role-based access

## 🔄 Workflow

1. Employee submits a laptop request.
2. The request is created in ServiceNow.
3. Manager approval is triggered.
4. After approval, a catalog task is created.
5. The task is assigned to the Laptop Fulfillment Team.
6. The team fulfills the laptop request.
7. The request is tracked until completion.
